# शिवराम Studio

A single-page Nepali text-to-video editor. Write a script, generate slides, add AI pictures, music and branding, then export a vertical MP4.

## Run locally

```bash
npm install
npm start
```

Open <http://localhost:8765> (the included `.env` sets `PORT=8765`; without a `.env` the server uses port 10000, or the `PORT` your host provides).

`npm install` is required once: narration uses the `ws` package to reach Microsoft Edge's speech service.

## Slide pictures (Cloudflare + Pollinations fallback)

Pictures are added in two modes:

- **Manual "Make slides"**: only slides with an `@img: description` line get an AI picture. Slides without `@img` stay text-only.
- **AI Writer**: every slide gets a picture. If the slide has `@img`, that description is used; otherwise the server summarizes the slide text in English.
- `@imglink: "1.png"` loads a local picture from `Rashi/` and never calls an AI provider. A missing `0.png` automatically falls back to `0.jpg`.
- Cloudflare Workers AI (`@cf/black-forest-labs/flux-1-schnell`) is tried first.
- If Cloudflare is out of its free daily neurons, rate-limited, or returns an error, the server automatically switches to Pollinations (`gen.pollinations.ai`) for the prompt summary and the picture.
- The switch happens per slide. If Cloudflare made 4 pictures and then hit its limit, the remaining slides continue with Pollinations instead of stopping or starting over.
- The browser only talks to `/api/slide-image`; both API keys stay on the server.

## आजको राशिफल (Gemini)

In the AI Writer, click **आजको राशिफल (१२ राशि)**. A Bikram Sambat calendar opens with today's Nepali date selected. Choose a date and confirm. The calendar closes immediately and sends this prompt to Gemini, with the chosen date on the second line:

```text
आजको राशीफल
२०८३ कार्तिक २१
बृहत पाराशर ज्योतिष शास्त्र अनुसार रिजल्ट बनाउनुहोस
हरेक राशीको अलग अलग बनाउनुहोस
हरेक राशीको ४ वटा फरक टपिकमा बनाउनु होस ।
```

While Gemini writes, the exact prompt and live progress appear in the AI Writer chat and the editor status bar. When it finishes, the chat also shows Gemini's four points for every rashi. If the selected model is busy or too slow, the editor automatically tries `gemini-2.5-flash`, `gemini-2.5-flash-lite` and `gemini-flash-latest`; the first attempt gets 15 seconds and each fallback 35 seconds. Gemini thinking is disabled so the 12-rashi JSON returns quickly. Errors stay visible in the chat and status bar without changing the previous slides. Reopen the calendar to retry, or close it again to cancel a pending request. When the answer arrives the editor builds 13 slides:

- The cover has `## तपाइको आजको राशीफल`, the chosen date, `# मेष देखि मीन राशिको भविष्यफल` and `@imglink: "0.png"`.
- Each rashi from मेष to मीन gets its own slide with four date-specific points generated by Gemini and `@imglink: "1.png"` through `"12.png"`.
- The Gemini API key and model come from **AI settings (⚙)**. The same date is reused from memory during the session, so it is not generated twice.

No AI pictures are generated for this template; every picture comes from the local `Rashi/` folder. The headings, date position, subtitle and image paths stay fixed; only the four points per rashi come from Gemini.

## Nepali narration (TTS)

Open **Media → Nepali narration** and press **Generate narration**. The editor creates one Nepali voice clip per slide and adds the clip length to that slide's duration (plus a short gap). A slide therefore never changes before its narration finishes, and starting playback in the middle of a slide starts the voice at the matching offset.

- Each slide row shows its voice length and has its own regenerate/remove button. **Remove all** clears the whole project's narration.
- Music is automatically ducked to 22% while a voice clip plays, then returns to full volume.
- Narration is mixed into both **direct export** (H.264 + AAC MP4) and the real-time **live recording** fallback.
- Voice clips are stored in IndexedDB with the project and restored when it is reopened. Backup JSON files include them too.
- If a slide's text changes, its row shows **Text changed — regenerate**; the old clip stays until you regenerate it.
- Each slide's narration text is limited to 2,000 characters.

The server tries these providers in order:

1. **Azure Speech** when `AZURE_SPEECH_KEY` and `AZURE_SPEECH_REGION` are set (default voice `ne-NP-HemkalaNeural`).
2. **Microsoft Edge neural voice**, which is free and needs no API key (default `ne-NP-HemkalaNeural`; set `EDGE_TTS_VOICE=ne-NP-SagarNeural` for the male voice). This is the recommended default.

Synthesized MP3s are cached in `.tts-cache/`, keyed by provider, voice and text. The folder is ignored by Git.

## Watermark

New projects start with a movable watermark at bottom center:

```text
पं. ज्यो. शिवराम पराजुली
९८४७४५२९०६
```

Edit its text, position, movement, color, size or transparency in **Brand**, or remove it with the trash button. With **Move around the screen**, the watermark starts at bottom center and roams the frame.

### Safety

Pictures are constrained for religious and cultural use:

- The summary prompt requires respectful, family-friendly scenes, fully clothed people in modest attire, and no violence or disturbing imagery.
- Explicit `@img` prompts are screened. If one contains unsafe wording, the server ignores it and summarizes the slide instead.
- Every final image prompt adds positive safety wording (modest clothing, respectful, serene).
- Both providers receive the same safe prompt. Pollinations additionally gets `safe=true` and a negative prompt that blocks nudity, violence, weapons, drugs, alcohol and text/watermarks.

This is a prompt-level safeguard, not a guarantee from the image model. Review generated pictures before publishing.

If Cloudflare is out of quota, the rest of the batch uses Pollinations automatically. If both providers fail, the app shows the reason from each one. Pollinations uses your Pollen balance, so it has its own limits.

### Credentials

Copy `.env.example` to `.env` and fill in:

```env
CLOUDFLARE_ACCOUNT_ID=...
CLOUDFLARE_API_TOKEN=...
POLLINATIONS_API=...
```

`POLLINATIONS_API` is optional but recommended. Without it there is no fallback when Cloudflare runs out. On a host such as Render, add all three variables in the service's environment settings. `.env` is ignored by Git and is never committed.

Narration credentials are optional. The free Microsoft Edge neural voice works with no setup. If you want an official key, add Azure Speech (the free tier includes the same `ne-NP-HemkalaNeural` voice):

```env
AZURE_SPEECH_KEY=...
AZURE_SPEECH_REGION=...
AZURE_TTS_VOICE=ne-NP-HemkalaNeural
```

Optional overrides: `CLOUDFLARE_TEXT_MODEL`, `CLOUDFLARE_IMAGE_MODEL`, `CLOUDFLARE_IMAGE_STEPS`, `POLLINATIONS_IMAGE_MODEL`, `POLLINATIONS_TEXT_MODEL`, `EDGE_TTS_VOICE`, `AZURE_TTS_VOICE`, `PORT`.

## Files

- `index.html` — the whole editor (UI, timeline, canvas and export).
- `server.js` — static server, `/ping` health check, `/Rashi/` pictures, the Cloudflare/Pollinations AI proxy, and the `/api/tts` narration proxy.
- `edge-tts.js` — free Nepali narration through Microsoft Edge's neural voice (v2 token, chunking and MP3 assembly).
- `Rashi/` — local rashi pictures used by `@imglink` (`0.png`, `1.png`–`12.png`).
- `.tts-cache/` — generated narration MP3s (created automatically, ignored by Git).
- `editor.original.html` — untouched backup of the original editor.
